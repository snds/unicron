# Contributing

Unicron is Sean Sands' personal design system. It is public so that his apps (Lockdown, Mailbird,
Synapse and Fontface) can install its release tarballs without logging in. It is not a community
project.

- **Pull requests from outside contributors aren't accepted.** They will be closed. This says
  nothing about the work: the project has one maintainer and no time set aside to review outside
  changes.
- **Issues may go unanswered.**
- **Forks are welcome.** Apache-2.0 lets you copy, change and ship Unicron. Keep `LICENSE` and
  `NOTICE` with it.

How Sean's own apps propose changes upstream is in
[docs/06-contributing.md](docs/06-contributing.md).
