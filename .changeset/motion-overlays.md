Overlays move onto the motion recipes. Dialog and Popover now open in 200ms and close in 120ms (both were 120ms each way), as transitions, so dismissing one mid-open turns round from where it is instead of restarting; they grow from 96% (Popover from its trigger edge) and Popover no longer slides 8px. ConfirmDialog, AdaptiveDialog and AdaptivePopover follow, since they are built on them. Tooltip, TruncatedText's tooltip and the command palette use the short pop, 120ms both ways. DropdownMenu (submenus and AdaptiveMenu's menu form included) uses the short pop instead of a slide, and the Select list animates for the first time; opened or closed from the keyboard, a menu or a list stays instant. Menus and lists are solid surfaces, so they fade whole. Sheet is unchanged. New recipes `motion-pop-fast`, `motion-pop-pointer` and `motion-fade`, and five new entries in `motionContracts` (dialog, popover, tooltip, menu, select), each with an optional `surfaces` list. If you restyled these popups with `data-open:animate-in`, `fade-in-*` or `slide-in-*` classes, those no longer apply; use the recipes. Fixed on the way: on a touch screen a tap on cut `TruncatedText` now keeps the full text open (the tap's own focus opened it and the same press closed it again, hidden until now by the 120ms exit animation). To keep a popup from growing, set `--motion-pop-from: 1` on it. Tokens: the descriptions of `--motion-fast` and `--motion-base` say what each is for now; no value changes.
